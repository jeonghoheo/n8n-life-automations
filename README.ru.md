# n8n — автоматизация повседневных задач

n8n на собственном хостинге (Docker): автоматизации для повседневной жизни, которые я проектирую, собираю и эксплуатирую сам.

[English](README.md) · [Русский](README.ru.md) · [한국어](README.ko.md)

## Автоматизации
- [ ] 1. Утренний брифинг — погода и курсы валют в Telegram (окружение готово, сценарий в работе)
- [ ] 2. Отслеживание изменений на сайтах
- [ ] 3. Сводки RSS и рассылок с помощью LLM
- [ ] 4. Мониторинг релизов и issue на GitHub
- [ ] 5. Приём форм и сообщений → запись в таблицу и уведомление

## Запуск
docker compose up -d, затем открыть http://localhost:5678

## Стек
n8n · Docker · Telegram Bot API
